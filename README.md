Quantum Coin Flip Simulator
===========================

Description:
------------
This is a simple Quantum Coin Flip simulator using Qiskit in Python.
It simulates a 1-qubit quantum circuit where Alice picks a secret bit (0 or 1), 
and Bob measures the result. The code also plots the quantum circuit and a histogram of the outcomes.

Requirements:
-------------
- Python 3.14 or the newest available version
- Qiskit
- Matplotlib

Installation:
-------------
1. Install Python (3.14 or later) from https://www.python.org/downloads/
2. Install Qiskit:
   Open a terminal or command prompt and run:
       pip install qiskit
3. Install Matplotlib:
       pip install matplotlib

How to Run:
-----------
1. Download or clone this repository.
2. Open a terminal or command prompt in the project folder.
3. Run the script:
       python quantum_coin_flip.py
4. The script will:
   - Display Alice's secret bit
   - Show Bob's measurement results
   - Draw the quantum circuit
   - Plot a histogram of the measurement outcomes

Notes:
------
- Make sure your Python environment has all dependencies installed.
- If you encounter errors, ensure you are using the latest version of Qiskit and Python.
- This is a beginner-friendly simulator, ideal for learning basic quantum circuits.
